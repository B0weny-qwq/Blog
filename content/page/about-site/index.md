# 关于本站

这个博客是我的个人成长记录，不是公共资料库，也不是供人随意搬运、截图、打印、断章取义的文章仓库。

我欢迎正常阅读、技术交流和善意讨论，也接受合理批评。

但我不欢迎恶意曲解、私自搬运、脱离上下文传播、拿片段内容做无意义攻击，或者不经说明就把文章当成自己的素材到处使用。

有些文章设置了访问限制，只是为了减少误读和无关传播。本站是静态页面，没有后端权限系统，仓库和页面本质上都可能被找到，所以这类限制并不是真正的保密机制，只是表达一种边界：这些内容不希望被随意扩散。

请尊重原创，也尊重一个人在成长过程中留下的不成熟记录。

引用、转载、搬运前，请先联系我并注明来源。

本站所有内容仅代表我个人在当时阶段的理解和表达，不代表任何组织、学校、团队或他人的观点。
